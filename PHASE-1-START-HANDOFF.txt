The database migration and pgTAP tests could not execute locally because this machine has neither Docker nor Podman and the repository is not linked to the hosted Supabase project. To validate or apply it manually:

With Docker/Podman:

  npm run db:start
  npm run db:reset
  npm run db:lint
  npm run db:test

Or against the hosted development project:

  npx supabase login
  npx supabase link --project-ref YOUR_PROJECT_REF
  npx supabase db push --dry-run
  npx supabase db push

RLS follows Supabase’s current guidance: explicit operation policies, named authenticated roles, indexed ownership columns, and cached auth.uid() evaluation. The Auth trigger uses a pinned empty search path as recommended for security-definer functions.
