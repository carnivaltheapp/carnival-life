# Carnival PlayHouse

PlayHouse is the Carnival Life application for creating, organizing, viewing, and managing Plays.

This directory is a Next.js App Router application and the configured root for the `carnival-playhouse` Vercel project. It currently contains the Phase 0 application shell only; Play management, authentication, persistence, and Google integrations begin in later phases.

See the [repository README](../../README.md) for installation, development, checks, and deployment instructions.
